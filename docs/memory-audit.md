# Total Peak Memory Audit

This audit is a developer-only baseline for total process peak memory. It measures Linux peak RSS (`VmHWM`) for synthetic fixtures and complements, but does not replace, the per-render output raster budget in `src/core/render_memory_budget.*`.

Run it from the repository root after building:

```sh
cmake --build build --target insidious_memory_audit
python3 tools/memory_audit.py --build-dir build
```

The Python wrapper creates temporary synthetic JPEG/ZIP fixtures under `/tmp`, runs each scenario in a separate process, prints a Markdown table, and removes the fixtures unless `--keep-fixtures` is passed.

## Baseline

Measured on 2026-06-30 with synthetic fixtures generated by `tools/memory_audit.py`. Peak RSS may vary slightly between runs because libvips, glib, and the system allocator do not produce bit-exact process memory histories.

| Scenario | Source | Fixture | Source MiB | Archive Entry Buffer MiB | Render MiB | Displayed MiB | Cache MiB | Peak RSS MiB | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| filesystem-fit | filesystem | large-fs.jpg | 6.42 | 0.00 | 5.01 | 5.01 | 0.00 | 99.71 | single display-sized fit decode |
| archive-fit | archive | large-archive.zip | 6.38 | 0.00 | 5.01 | 5.01 | 0.00 | 93.05 | streamed archive entry plus fit decode |
| zoom-render | filesystem | large-fs.jpg | 6.42 | 0.00 | 23.73 | 23.73 | 0.00 | 96.76 | scale=2 region-based zoom decode |
| prefetch-simulation | filesystem | prefetch-*.jpg | 10.83 | 0.00 | 5.01 | 5.01 | 15.02 | 117.66 | current displayed image plus current/neighbor cache entries |

## Interpretation

- The current render budget limits the final output raster, not total process peak memory.
- Archive display decode streams the selected entry into libvips instead of buffering the full entry first. Clipboard original-byte copy remains a separate bounded full-read path.
- The recorded non-fit zoom baseline assumes the default `regionRenderingEnabled=true`, which decodes the visible region plus overscan instead of the full zoomed raster. Disabling this setting is intentionally higher-memory and can hit the render budget sooner.
- Prefetch adds decoded cache pressure. In this synthetic fit-sized case the measured peak stays well below the decoded cache budget, but the cache bytes are additive with libvips working memory and displayed raster state.

## Follow-up Candidates

- If real-world archive measurements are worse than this synthetic baseline, revisit archive streaming, random-access, and format-specific loader behavior.
- Add thumbnail generation/cache scenarios before increasing thumbnail cache size or widening preloading beyond the visible/nearby range.
