# Risks and open questions

## Архивы без распаковки на диск

Требование «архив не должен распаковываться на диск» критично для privacy, но оно сильно влияет на выбор библиотек. Нужно заранее проверить, умеют ли выбранные библиотеки читать ZIP/RAR/7Z entries streaming/in-memory.

Если библиотека требует временной распаковки на диск, она не подходит для нормального режима работы.

## Парольные архивы

Текущее базовое решение:

- prompt показывается при открытии архива, если libarchive сообщает, что нужен пароль;
- при неверном пароле prompt повторяется до успешного ввода или отмены;
- пароль хранится только в памяти активного archive source и очищается при смене файла, папки или архива;
- пароль не попадает в `ImageEntry`, cache key, settings, UI labels или документацию runtime-состояния.

Оставшийся риск: расширенная диагностика encrypted archives зависит от возможностей libarchive и конкретного формата.

## RAW

RAW — это не один формат, а семейство форматов с разным поведением, preview images, color processing и тяжёлыми зависимостями. RAW не должен входить в MVP.

## AVIF и JPEG XL

AVIF и JPEG XL зависят от поддержки в выбранном image stack. Их лучше добавлять после базовой архитектуры форматов.

## Качество рендеринга

Требование «максимально возможное качество» нужно уточнить технически:

- high-quality scaling;
- правильная обработка alpha;
- корректная ориентация;
- ICC/color management;
- отсутствие лишнего размытия;
- корректная работа на HiDPI.

Для MVP достаточно качественного scaling без явной порчи изображения. Color management можно вынести в отдельный этап.

## Колесо мыши

Сейчас колесо мыши по умолчанию задано как переход между изображениями. Это удобно для image viewer, но конфликтует с распространённым ожиданием zoom через wheel.

Зафиксированная схема по умолчанию:

- wheel = next/previous;
- Ctrl + wheel = zoom with cursor anchor;
- Shift + wheel = no action;
- пользователь может изменить wheel actions в Preferences;
- left click = temporary default zoom centered on the click point, or restore fit/actual size after temporary zoom;
- left drag = pan;
- right drag = zoom-to-selection rectangle.

Оставшийся риск: если пользователь перенастраивает wheel на zoom, next/previous остаются доступными через toolbar/shortcuts, но привычка листать колесом меняется. Документация и settings labels должны оставаться ясными.

## No traces vs settings

Требование «никаких следов» не должно запрещать обычный settings file. Но settings не должны содержать историю просмотра, recent files, recent folders, recent archives, persistent thumbnails или passwords.

## Миниатюры

Thumbnail panel может стать источником подвисаний и persistent следов. Поэтому:

- thumbnails создаются только по требованию;
- генерация должна быть lazy/asynchronous;
- cache только memory-only;
- при закрытии приложения thumbnails исчезают.

## Большие папки

Большие папки не должны блокировать UI. Нужно продумать:

- async scanning;
- частичное отображение результатов;
- отмену старого сканирования при открытии нового источника;
- стабильное поведение, если файлы меняются во время просмотра.

## Естественная сортировка

Natural sort должен корректно обрабатывать имена вида:

- `1.jpg`, `2.jpg`, `10.jpg`;
- `image-001.jpg`, `image-002.jpg`;
- разные регистры расширений;
- Unicode-имена.

## Память

Опасность: большие изображения и prefetch могут быстро съесть память. Cache должен иметь лимиты и уметь освобождать decoded images.
