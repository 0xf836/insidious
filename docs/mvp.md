# MVP

## Цель MVP

Получить маленькую, стабильную и реально используемую версию просмотрщика, которая хорошо открывает обычные изображения и папки на Linux.

MVP не должен пытаться сразу закрыть все требования. Его задача — проверить архитектуру viewer pipeline, UI responsiveness, навигацию и базовое качество рендеринга.

## Входит в MVP

- Запуск нативного GUI-приложения на Linux.
- Главное окно с центральной областью просмотра.
- Открытие одного изображения.
- При открытии одного изображения — использование родительской папки как контекста просмотра.
- Открытие папки с изображениями.
- Открытие обычного ZIP/7z/RAR архива с изображениями без распаковки на диск.
- Естественная сортировка по имени.
- Переход к следующему/предыдущему изображению.
- Переход к первому/последнему изображению.
- Отображение текущего номера и общего количества.
- Отображение имени файла.
- `fit to window`.
- `actual size` / 100%.
- Zoom in / zoom out.
- Перетаскивание увеличенного изображения.
- View-only rotate на 90° влево/вправо.
- Fullscreen.
- Базовый drag'n'drop одного файла и папки.
- Базовая статусная строка.
- Левая панель списка файлов без thumbnails.
- Правая панель `Info` с базовой информацией и компактным EXIF.
- Быстрый переход по имени файла.
- Асинхронная загрузка изображения или загрузка без блокировки UI.
- Memory cache для текущего, предыдущего и следующего изображения.
- Понятные сообщения об ошибках без сброса текущей коллекции и навигации.

## Форматы MVP

Минимально:

- JPEG;
- PNG;
- WebP;
- BMP.

Желательно, если выбранный стек даёт почти бесплатно:

- GIF.
- TIFF.
- AVIF.
- JPEG XL.

## Не входит в MVP

- Сохранение паролей архивов.
- RAW.
- Панель миниатюр.
- Настройка горячих клавиш.
- Глубокая настройка антиалиасинга/фильтров.
- Persistent settings UI.
- Настраиваемый или fuzzy быстрый переход по имени файла.
- Рекурсивный просмотр папок.

## Граница поддержки архивов в MVP

MVP поддерживает ZIP/7z/RAR архивы через libarchive как коллекцию изображений без распаковки на диск. Для архивов с паролем пароль запрашивается при открытии, хранится только в памяти текущего source и очищается при смене файла/папки/архива. Сохранение паролей, оптимизация повторного чтения больших архивов и расширенная диагностика ошибок остаются следующими этапами.

## Acceptance criteria MVP

MVP считается готовым, если пользователь может:

1. Запустить приложение.
2. Открыть изображение из папки.
3. Переключаться на соседние изображения этой папки.
4. Открыть папку напрямую.
5. Открыть обычный архив с изображениями без распаковки на диск.
6. Использовать zoom, pan, fit to window, actual size.
7. Перейти в fullscreen и выйти из него.
8. Перетащить файл, папку или архив в окно.
9. Получить понятное сообщение при ошибке вместо crash.
10. Закрыть приложение без появления истории просмотренных файлов или persistent cache.
