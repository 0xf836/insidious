# MVP

## Цель MVP

Получить маленькую, стабильную и реально используемую версию просмотрщика, которая хорошо открывает обычные изображения, папки и базовые архивы на Linux.

MVP не должен пытаться сразу закрыть все требования. Его задача — проверить архитектуру viewer pipeline, source tree, UI responsiveness, навигацию, базовое качество рендеринга и privacy boundaries.

## Входит в MVP

- Запуск нативного GUI-приложения на Linux.
- Главное окно с центральной областью просмотра.
- Открытие одного изображения.
- При открытии одного изображения — использование родительской папки как контекста просмотра.
- Открытие папки с изображениями.
- Открытие обычного ZIP/7z/RAR архива с изображениями без распаковки на диск.
- Естественная сортировка по имени.
- Переход к следующему/предыдущему изображению.
- Переход к первому/последнему изображению.
- Отображение текущего номера и общего количества.
- Отображение имени файла.
- `fit to window`.
- `actual size` / 100%.
- Embedded ICC color management с конвертацией rendered raster в sRGB, включённый по умолчанию и отключаемый в настройках.
- Zoom in / zoom out.
- Перетаскивание увеличенного изображения.
- View-only rotate на 90° влево/вправо через `View`, toolbar, fullscreen top overlay и shortcuts; поворот сбрасывается при переходе на другое изображение.
- Fullscreen.
- Drag'n'drop и Open File для одного файла/архива или однородного набора изображений либо архивов; drag'n'drop также принимает однородный набор папок; смешанные наборы отклоняются.
- Базовая статусная строка.
- Левая панель `Files` с деревом папок и нижними вкладками `List`/`Thumbnails` для изображений выбранной папки; thumbnail generation lazy/asynchronous, только при открытой видимой вкладке, с memory-only cache. Toolbar `Sorting` меняет runtime-сортировку файлов по name/type/size/date asc/desc.
- Базовое сравнение изображений: multi-select в `List`/`Thumbnails`, контекстное меню `Compare` и drag'n'drop выбранных элементов на видимую вкладку `Compare` с добавлением изображений из разных папок текущего source, Row/Grid/Carousel modes для 1-8 изображений с удалением элементов из compare-сессии, Hover Switch mode для ровно двух изображений, runtime-only alignment presets, memory-only сессия, асинхронный memory-only decode/cache, вкладка `Compare` и clean fullscreen compare layout без edge overlays.
- Правая панель `Info` с базовой информацией, статусом color profile и компактным EXIF.
- Быстрый переход по имени файла.
- Базовое окно настроек для viewer/input defaults, режима ЛКМ zoom, wheel actions, zoom step, color management, core viewer keyboard/mouse shortcuts, fullscreen edge trigger zones и запоминания layout без истории просмотра.
- Асинхронная загрузка изображения или загрузка без блокировки UI.
- Memory cache для текущего, предыдущего и следующего изображения.
- Понятные сообщения об ошибках без сброса текущей коллекции и навигации.

## Форматы MVP

Реализуемый MVP-набор:

- JPEG;
- PNG;
- WebP;
- BMP;
- DIB.

Остальные форматы рассматриваются отдельными этапами после стабилизации viewer pipeline:

- GIF animation;
- TIFF;
- AVIF;
- JPEG XL;
- RAW.

## Не входит в MVP

- Сохранение паролей архивов.
- RAW.
- GIF animation.
- TIFF.
- AVIF.
- JPEG XL.
- Persistent thumbnail cache.
- Расширенные режимы сравнения за пределами текущих Row/Grid/Carousel/Hover Switch/alignment presets.
- Глубокая настройка антиалиасинга/фильтров.
- Display-profile/monitor-profile matching.
- Расширенные настройки rendering/statusbar/quick jump/thumbnails.
- Настраиваемый или fuzzy быстрый переход по имени файла.
- Рекурсивная коллекция, автоматически включающая все изображения из подпапок.

## Граница поддержки архивов в MVP

MVP поддерживает ZIP/7z/RAR архивы через libarchive как коллекцию изображений без распаковки на диск. Для архивов с паролем пароль запрашивается при открытии, хранится только в памяти текущего source и очищается при смене файла/папки/архива. При открытии нескольких архивов один введённый пароль применяется к выбранным архивам; если какой-либо архив его отклоняет, открытие всего multi-archive source отменяется. Сохранение паролей, оптимизация повторного чтения больших архивов и расширенная диагностика ошибок остаются следующими этапами.

## Acceptance criteria MVP

MVP считается готовым, если пользователь может:

1. Запустить приложение.
2. Открыть изображение из папки.
3. Переключаться на соседние изображения этой папки.
4. Открыть папку напрямую.
5. Открыть обычный архив с изображениями без распаковки на диск.
6. Использовать zoom, pan, fit to window, actual size.
7. Перейти в fullscreen и выйти из него.
8. Перетащить файл, папку, архив или однородный набор изображений/папок/архивов в окно.
9. Получить понятное сообщение при ошибке вместо crash.
10. Закрыть приложение без появления истории просмотренных файлов или persistent cache. Settings file допускается, если он содержит только non-history preferences.
