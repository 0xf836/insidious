# UI specification

## Общий ориентир

Интерфейс ориентируется на классический быстрый image viewer: верхнее меню/toolbar, центральная область просмотра, левая навигационная панель и нижняя статусная строка. Примерный визуальный ориентир — FastStone MaxView-like layout: дерево/список слева, изображение по центру, toolbar сверху, statusbar снизу.

## Главное окно

Главное окно состоит из:

- центральной области просмотра изображения;
- верхнего меню или панели действий;
- нижней статусной строки;
- левой панели навигации;
- опциональной правой панели расширенной информации.

## Центральная область просмотра

Центральная область должна:

- показывать текущее изображение;
- использовать нейтральный тёмный фон;
- поддерживать `fit to window`;
- поддерживать `actual size`;
- поддерживать zoom;
- поддерживать pan при увеличении;
- не мерцать при переключении изображений;
- не блокировать весь интерфейс во время загрузки следующего изображения.
- при transient loading во время переключения или zoom оставлять предыдущий raster на экране и показывать ненавязчивый полупрозрачный overlay вместо чёрного экрана.

## Верхняя панель

Верхняя панель может содержать:

- открыть файл;
- открыть папку;
- открыть архив;
- назад / вперёд;
- первый / последний;
- zoom in / zoom out;
- fit to window;
- actual size;
- rotate left / rotate right;
- fullscreen;
- переключение левой панели;
- переключение правой панели.

Точный набор кнопок можно уточнять после выбора GUI toolkit.

## Нижняя статусная строка

Статусная строка показывает:

- разрешение изображения;
- размер файла;
- масштаб;
- номер текущего изображения и общее количество;
- имя файла или относительный путь внутри коллекции.

Пример:

```text
3412 x 2188 · 7.47 MP · 1.8 MB · 42% · 12 / 240 · folder/image.jpg
```

## Левая панель

Левая панель имеет два режима:

1. Навигация по папкам/архиву.
2. Миниатюры.

Текущая реализация навигационного режима — dock-панель `Files` со списком файлов текущей коллекции. По умолчанию она открыта слева, может быть скрыта через меню `View`, синхронизирует выделение с текущим изображением и переключает изображение по выбору строки мышью или клавиатурой. Панель миниатюр не должна строить thumbnails заранее: миниатюры создаются только после открытия этой панели.

## Правая панель

Правая панель опциональна. Она показывает расширенную информацию:

- EXIF;
- формат;
- путь;
- дата изменения;
- технические параметры изображения;
- возможно, ICC/color profile information.

Правая панель не входит в MVP.

## Fullscreen

Fullscreen режим должен быть максимально чистым:

- центральная область просмотра изображения;
- минимум UI;
- в углу настраиваемая краткая строка информации;
- скрытые боковые панели, появляющиеся при приближении курсора к краю;
- возможность выйти из fullscreen через `Esc`.

## Мышь

Базовое поведение:

- колесо мыши: следующее/предыдущее изображение;
- `Ctrl + wheel`: zoom in / zoom out;
- next/previous через toolbar, shortcuts или wheel по умолчанию сбрасывает zoom и pan в установленный базовый режим `fit` или `actual size`; если следующего/предыдущего изображения нет, текущий entry перерендеривается с тем же сбросом;
- простой клик левой кнопкой: временный zoom 200% с центровкой по точке клика;
- простой клик левой кнопкой после click/rectangle zoom: возврат в исходный режим `fit` или `actual size`;
- зажатая левая кнопка: pan/hand mode только вне базового `fit`; простой клик ЛКМ продолжает работать как zoom/restore;
- зажатая правая кнопка: прямоугольник zoom-to-selection;
- drag'n'drop в окно: открыть соответствующий источник.
- double click - переход в Fullscreen/выход из него; временный zoom по простому клику при double click не срабатывает

Открытый вопрос: нужно определить поведение `Shift + wheel`.

## Клавиатура

Базовые действия:

- next image;
- previous image;
- first image;
- last image;
- zoom in;
- zoom out;
- fit to window;
- actual size;
- rotate left/right;
- fullscreen;
- show/hide side panels;
- open file;
- open folder;
- open archive;
- close app.

Конкретные shortcuts лучше зафиксировать отдельным документом после выбора toolkit.
